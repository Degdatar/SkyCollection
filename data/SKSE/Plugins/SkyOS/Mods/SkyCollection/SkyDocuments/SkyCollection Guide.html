ITEM INVENTORY & COLLECTION LOG

SkyCollection

Browse save-specific item and location discoveries; SkyCounter UI supplies optional item icons and first-visit location screenshots.

Requirements

  • Skyrim Special Edition / Anniversary Edition Latest Version (supported runtime).
  • SKSE Latest Version.
  • PrismaUI Latest Version.
  • SkyOS Latest Version.
  • SkyCounter UI Latest Version.

How collection works

Automatic discoveries

Items are recorded as they enter your inventory. You do not need to open inventory or highlight an item.

Separate saves

Each save stores its own collection in that save's SKSE co-save. Loading a different save switches to that save's discoveries.

Icons

SkyCollection only reads and displays icons already rendered and cached by SkyCounter UI. Pickup-triggered item rendering is initiated by SkyCounter UI, never by SkyCollection. Cached icons are kept under Data/SKSE/Plugins/SkyOS/Mods/SkyCounterUI/Icons.

Categories and filters

Browse weapons, armor, consumables, books, crafting materials, gems, quest items, and other records. Use the category tree, plugin filter, search, recency filter, or estimated rarity filter to narrow the catalog.

Rarity is an estimate. Skyrim does not expose a universal rarity field on every item. SkyCollection marks quest items, dragon claws, dragon masks, and records with unique-item flags as Legendary; equipment tiers and common naming patterns help estimate lower tiers. Mod authors can use different conventions, so check the item itself when the label matters.

Resetting the active save

Use SkyViewer → SkyCollection → Reset Collection to clear the active save's discovered-item list. The reset does not delete cached icon files. Save the game afterward so the empty catalog is written to that save.

Display options

  • Hide plugin names, FormIDs, categories, or collected counts.
  • Hide rarity badges or the plugin picker.
  • Choose the default sort order.
  • SkyCounter UI captures item icons and first-visit location screenshots; SkyCollection reads these shared caches and displays them with save-specific records.
  • Disable the SkyCollection page and its launch points while continuing automatic item tracking.

Browse the catalog

Find an item

  1. Choose a collection category from the left-side category list.
  2. Search by item name or FormID, or narrow the visible entries using the plugin picker.
  3. Use rarity and recent-discovery filters to focus the results.
  4. Sort by name, collection count, or estimated rarity in the SkyViewer module preferences.

Read a collection card

Depending on your display preferences, a card can show its icon, name, category and subcategory, owning plugin, FormID, rarity label, and number collected. A missing image means no cached icon is available yet; SkyCollection does not start rendering one.

Discovery, saves, and artwork

Save-specific records

Each save stores its own discovered items and locations in its SKSE co-save. Switching saves changes the collection being shown. The catalog is not a single global list shared by every character.

Shared image caches

SkyCounter UI owns item-icon rendering and location screenshot capture. Its cache is shared outside the save under Data/SKSE/Plugins/SkyOS/Mods/SkyCounterUI/Icons/ and .../Locations/. SkyCollection only reads and displays images already in those caches.

When a new image is missing

Check SkyCounter UI's Render item icons or Capture location screenshots option in SkyViewer → Modules → SkyCounter UI. Existing cached images can remain visible even when future rendering is turned off.

Rarity is an estimate

Quest and unique-item flags identify some Legendary records. Other tiers are estimated from equipment data and common naming patterns; mod authors may use different conventions.
